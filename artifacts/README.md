# Validation artifacts

`validation.json` and `validation.md` are generated by `scripts/validate_claims.py`. The JSON
contains per-case replay and reduction records, ground-truth confusion counts, runtime metadata,
source/runner hashes, and machine-checked assertions. The Markdown file is the concise report.

The experiments are deterministic, synthetic ground-truth validation. They exercise the real
replay, reduction, and regression aggregation code without external model calls; they do not claim
that 6.25% is a naturally observed production drift rate.
